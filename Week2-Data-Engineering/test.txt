### **2. Week 1: Folder & File Content Plan**

Here is what you should put inside the **Week 1** sub-folders to ensure your first week is a success.

#### **Day 1: Standards & Linting**
* **File:** `Day1/messy_code.py`
    * *Content:* A script with zero type hints, bad variable names (`x`, `y`), and inconsistent spacing.
* **File:** `Day1/solution.py`
    * *Content:* The same logic but using **Pydantic** for validation and **Type Hints**.
* **Concept to Teach:** Why "linting" is a requirement for code reviews.

#### **Day 2: The DataLoader (Composition)**
* **File:** `Day2/data_loader.py`
* **Activity:** Build the `DataLoader` component from your TOC.
* **Consultant Tip:** Show how to use **Composition** to plug in different "Parsers" (CSV vs. JSON) without changing the main loader logic.

#### **Day 3: Engine Interfaces (ABCs)**
* **File:** `Day3/engine_interface.py`
* **Content:**
    ```python
    from abc import ABC, abstractmethod

    class BaseAIEngine(ABC):
        @abstractmethod
        def generate_response(self, prompt: str) -> str:
            pass
    ```
* **Concept to Teach:** "Coding to an Interface." This is how you swap OpenAI for a local Llama model later.

#### **Day 4: High-Performance Async**
* **File:** `Day4/async_client.py`
* **Activity:** Use `asyncio.gather` to call a mock API three times simultaneously.
* **Concept to Teach:** I/O concurrency. Why synchronous code kills AI performance.

#### **Day 5: The Platform CLI**
* **File:** `Day5/cli_tool.py`
* **Activity:** Use the `click` library to create a command: `python cli_tool.py run-pipeline`.
* **Concept to Teach:** Turning code into a professional tool for DevOps/SRE teams.
